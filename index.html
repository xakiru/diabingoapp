Votre cours d’espagnol

Commencez par les fondations, puis avancez à votre rythme.

Comment utiliser ce cours ?

1. Choisissez un chapitre, puis une leçon.
2. Lisez l’explication et les exemples. « Écouter » lit la phrase en espagnol si une voix est disponible sur votre appareil.
3. Choisissez une réponse, puis appuyez sur « Vérifier ». Vous pouvez réessayer autant que vous voulez.
4. Faites le petit exercice oral, puis utilisez « Marquer cette leçon comme terminée ».
5. À la fin du chapitre, passez le test. Consultez ensuite vos scores dans « Ma progression ».

Les mots de base viennent d’une liste de vocabulaire Duolingo. Vous pouvez suivre le cours sans connaître cette liste : les exemples sont traduits. Les nouvelles conjugaisons sont expliquées dans chaque leçon. Aucun compte n’est nécessaire.
